## Row 2 Probe 9 + Probe 9b Detailed Finding

**DEF-§5.1-UPDATE-PARTIAL** includes Probe 9's verdict (POST) and Probe 9b's verdict (PATCH): **FIELD-CLEAR NOT SUPPORTED ON EITHER ENDPOINT**.

**Probe 9 empirical evidence (POST /model/update, 2026-05-15, v1.83.10):**

```
seed status=200; verify status=200 (with timeout:null);
witness status=200;
litellm_params={timeout, use_in_pass_through, use_litellm_proxy, merge_reasoning_content_in_choices, model, rpm};
timeout=300 (previous value preserved — null-clear IGNORED)
```

The test POSTed `{..., "litellm_params": {"model": "openai/gpt-3.5-turbo", "api_key": "sk-fake-not-used-at-rest", "rpm": 100, "timeout": null}, ...}` (literal JSON `null` for `timeout`). The subsequent `GET /model/info` showed `timeout=300` — the value from the PRIOR seed step. LiteLLM silently discarded the `null` and preserved the previous value.

**Probe 9b empirical evidence (PATCH /model/{model_id}/update, 2026-05-15, v1.83.10):**

```
create status=200 model_id=12d472f9-6567-4078-a61a-df223fade5b4; seed timeout=45;
PATCH /model/12d472f9-6567-4078-a61a-df223fade5b4/update status=200 (with timeout:null);
witness status=200;
litellm_params={use_in_pass_through, use_litellm_proxy, merge_reasoning_content_in_choices, model, rpm, timeout};
timeout=45 (previous value preserved — null-clear IGNORED)
```

The test PATCHed `{"litellm_params": {"timeout": null}}` against the path-parameterized PATCH endpoint. HTTP 200 was returned, but `GET /model/info` showed `timeout=45` — the seed value unchanged. PATCH accepts partial-merge updates (non-null fields update; confirmed rpm:99 updates rpm correctly) but silently discards null values just like POST.

**Endpoint existence confirmation:**
- `GET /openapi.json` on running container lists `PATCH /model/{model_id}/update` in paths
- `OPTIONS /model/{id}/update` returns HTTP 405 with `Allow: PATCH` header
- Endpoint is NOT a 404 — it is a real route that accepts PATCH requests

**Implication for D-02:** Both POST /model/update (Probe 9 ✗) and PATCH /model/{id}/update (Probe 9b ✗) ignore null. D-02 cannot be salvaged via the PATCH endpoint. The explicit-null mechanism is INVALID for LiteLLM 1.82.x / 1.83.x. The orchestrator MUST amend CONTEXT.md D-02 to delete-and-recreate semantics before plan 03-02 codes the reconciler update body construction.
